# Codex Pet Credits

Windows 上附着于 Codex 自带宠物的 credits 状态栏。采用本机已有的 Node.js 24 和 Windows .NET Framework WPF，无第三方生产依赖。

## 启动

1. 构建：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build.ps1`。
2. 创建启动入口：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Create-Shortcut.ps1`。
3. **完整退出 Codex 后，双击项目根目录的 `Codex + Credits.lnk`。** 该入口同时启动 Codex 和挂件，并仅在本机回环地址开启任务识别接口。
4. 在 Codex 中打开宠物。挂件跟随宠物显示、隐藏和移动；Codex 退出后挂件和数据进程自动退出。

启动器不会强行结束现有 Codex 进程。已经运行的客户端无法补加调试参数，因此首次启用需要退出再打开。建议将此快捷方式固定到常用启动位置。挂件不随 Windows 登录启动。

## 使用

| 控件 | 行为 |
|---|---|
| `−` / `∿` / `≡` | 极简、趋势、详细；再次点击当前展开模式可收起，选择自动保存 |
| 统计范围 | 当前任务、本机汇总、主要任务、主要项目；比较曲线最多三条 |
| 时间窗口 | 1h、6h、24h、7d、30d；每个范围分为48个等长区间，单位为区间内估算 credits |
| `⋯` | 展开外观设置与说明；三个密度都能调整背景不透明度（40%–100%）和浅色／深色 |
| 任务标题 | 单行省略；点击查看可复制的完整标题，长内容在限定高度内滚动 |
| `!` | 预计额度提前耗尽；简短悬停提示，完整依据位于折叠说明中，不发送系统通知 |
| 详细面板 | 重置时间；模型、近期消耗和其他额度按需展开 |
| 右键 | 密度切换、刷新额度、退出挂件 |
| Esc | 收起；图表获得焦点后左右方向键可查看区间 |

跟随动画和平滑曲线尊重 Windows 减少动画设置。曲线采用单调三次插值，不产生额外峰值；同一任务的数据更新使用短时插值过渡，切换任务或时间窗口时直接初始化新曲线。48 个区间与固定时间边界对齐，避免每次刷新重新分桶；末个区间可能尚未结束。

面板通常位于宠物上方，并避开原生浮动条；屏幕边缘空间不足时自动改到下方或其他可用方向，恢复空间后回到上方。拖拽期间直接跟随指针，松手后短时平滑归位；切换方向时避免动画路径穿过宠物。不是固定左右布局。多显示器定位使用原生物理坐标和宠物 DOM 局部坐标，支持负坐标与缩放比例。

## 数据口径

### 官方剩余额度

通过 Codex 官方 App Server 的 `account/rateLimits/read` 获取主 `codex` 额度池。按窗口长度识别周额度，不假设 `primary` 就是五小时。剩余量保留官方百分比；接口没有给出订阅周额度总 credits，不能编造换算。

其他额度池在详细面板各占一行。没有可用数据源的 ChatGPT Pro 剩余消息次数已删除。

### 消耗统一为估算 credits

每个模型调用按当前版本官方费率计算：

```text
((输入 − 缓存输入) × 输入费率 + 缓存输入 × 缓存费率 + 输出 × 输出费率)
÷ 1,000,000 × 已知的 Fast 倍率
```

- 缓存输入是总输入的子集，推理输出是总输出的子集，均不重复累加。
- 按调用当时的模型计算，不把线程累计量全部套用当前模型。
- 缺少速度档位记录时按标准费率估算，并在界面注明；未知模型、未知档位或未明确计费的缓存写入记为缺失，合计明确为已知部分。
- 费率表日期为 **2026-09-15**。历史曲线用该版本费率重新估算，不宣称复原历史账单；Sol 当前价格为促销费率。
- 本机汇总包含本机可读日志；**不等于整个账户所有设备的完整消耗**。官方每日总 token 缺少模型和缓存分项，因此没有伪造账户每日 credits 曲线。
- 官方 `account/usage/read {threadId}` 如果返回 `threadUsage.estimatedUsageCreditsMicros`，在详情中单列该任务的服务端累计估算，不与本机区间量相加。该数据与当前选择的时间窗口含义不同。
- 只展示最近35天已索引记录范围内的数据。删除的历史、未同步的远端任务、工具额外费用可能不在其中；当前远端任务没有本地记录时不冒充本地任务。

### 单一耗尽预测

从实际额度百分比变化学习活跃工作速率，以历史小时级活跃概率估计未来工作时长，再由近期速度修正。输出一个耗尽时间，或“预计可用至重置”。预测是对已观察行为的估计，不是保证。

- 至少需要两个有活动记录的日期、一小时连续额度采样、两个百分点的可观察变化。
- 不跨采样中断或额度重置推算瞬时速度；额度数据超过5分钟未更新时暂停预测。
- 后台每30秒刷新额度、每10秒增量索引本机日志、每秒识别当前任务。宠物几何信息独立以40毫秒间隔采样，原生跟随以16毫秒计时器更新，不触发额度或图表重算。
- 只在 Codex 运行期间采样。界面隐藏仍采样；客户端退出停止采样。多设备消耗会降低预测可靠性。

## 当前任务识别与附着

通过本机 CDP 读取可见输入框的 `data-above-composer-conversation-id`。优先当前获得焦点的 Codex 页面；切到其他应用时保留最后查看任务。识别失败时标明使用最近活跃任务。子代理按父任务归组。

宠物使用 `[data-testid="avatar-mascot-button"][data-avatar-mascot="true"]` 的稳定容器边界，而不是每帧变化的美术像素或透明窗口整体。通过 Codex 进程、窗口类和工具窗口样式识别唯一宠物窗口；不再要求拖拽中的 DOM 尺寸与原生窗口同步。原生浮动条的可见交互区域作为避让障碍物。短暂采样失败保留上一次几何信息；子元素的隐藏事件不会被误判为整个宠物关闭。这些内部 DOM 标记可能随 Codex 升级而变化，需兼容性验证。

## 项目结构

```text
src/backend/    官方接口、本机增量索引、credits 核算、预测、CDP 元数据
src/windows/    WPF 窗口、图表、跟随控制器、纯几何避让与原生接口
scripts/        构建、启动、快捷方式生成、真实数据 smoke 检查
tests/          核算与增量读取测试、独立演示数据
build/          构建产物（不入 Git）
artifacts/      测试结果与渲染预览（不入 Git）
prev/           用户旧版本，默认排除；仅曾研究获准的当前任务识别思路
```

本机设置、额度历史和仅含用量的索引缓存位于 `%LOCALAPPDATA%\CodexPetCredits`。应用不读取认证文件，不存储提示词或聊天正文。日志中的任务标题和项目路径仅用于本机界面；不会上传到外部统计服务。

## 验证

```powershell
node --test tests/*.test.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Test-Frontend.ps1
node scripts/Smoke.mjs
.\build\CodexPetCredits.exe --render "$PWD\artifacts\previews"
```

`Smoke.mjs` 只读连接真实 Codex 账户，输出额度可用性与用量记录计数；不触发模型推理。渲染使用明确标记的演示数据，产出三种密度的浅色／深色 PNG。

当前已完成12项数据测试、6项前端回归测试、WPF 构建及六种界面渲染。回归覆盖首帧曲线越界、长标题、四角和边缘避让、浅深色切换、切换任务串线及子元素隐藏事件。真实额度和任务数据此前已由用户确认；新版已在正在运行的宠物上完成可见窗口定位检查，验证了负坐标屏幕上的附着。连续大范围拖拽的手感、跨不同缩放显示器拖动仍需要实际操作确认，未把静态检查当作动态验证。
